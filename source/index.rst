Welcome to Music Splitter Documentation
=====================================

Project Overview
-----------------
Music Splitter is a Python application that splits songs into smaller segments based on given parameters.

Installation
------------
To install the project, use the following command:

.. code-block:: bash
   pip install music-splitter

Usage
------
To use the application:

.. code-block:: bash
   python main.py
