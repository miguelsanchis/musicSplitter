# YouTube Playlist Stem Separator 🎵  

A Python-based tool that uses the **Demucs** library to extract individual stems (vocals, bass, drums, etc.) from songs in YouTube playlists. Designed for DJs and music enthusiasts, this tool simplifies track isolation for live sets, remixes, and music production.  

## ✨ Features  

- Automatically downloads and processes tracks from YouTube playlists  
- Separates stems using **Demucs**  
- Streamlines workflow for DJs and producers
